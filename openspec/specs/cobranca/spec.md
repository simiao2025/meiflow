# cobranca Specification

## Purpose
Gestão de cobranças via PIX, link de cartão e outros métodos de pagamento.

## Requirements
- Geração de QR Code PIX dinâmico.
- Criação de links de pagamento.
- Acompanhamento de status da cobrança.

## Acceptance Criteria
- [ ] Componentes extraídos e testáveis.
- [ ] Código com baixa complexidade cognitiva.
