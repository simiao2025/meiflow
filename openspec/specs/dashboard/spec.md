# dashboard Specification

## Purpose
Dashboard central para o MEI (Hub Financeiro) com visualização de faturamento, alertas e resumo de ações pendentes.

## Requirements
- Visualização de faturamento atual vs limite anual.
- Resumo de saldos e transações recentes.
- Alertas proativos de pendências (DAS, etc.).

## Acceptance Criteria
- [ ] Componente desacoplado e testável.
- [ ] Refatoração concluída (redução de complexidade cognitiva).
- [ ] Métricas de saúde do código melhoradas (fallow).
