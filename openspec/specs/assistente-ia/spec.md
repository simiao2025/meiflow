# assistente-ia Specification

## Purpose
Chatbot de IA conversacional para assistenten do MEI, com streaming de respostas e integração ao backend Python (FastAPI/LangGraph).

## Requirements
- Interface de chat com streaming SSE.
- Histórico de mensagens persistente.
- Comandos rápidos para ações fiscais/financeiras.

## Acceptance Criteria
- [ ] Refatoração concluída com componentes extraídos.
- [ ] Interface responsiva e testável.
