# Design: OpenSpec Baseline

## Overview
A estrutura OpenSpec será usada para documentar todas as mudanças significativas no projeto, mantendo um histórico claro e vinculando cada mudança a uma especificação de capability.

## Structure
- `openspec/specs/`: Especificações de alto nível das capabilities.
- `openspec/changes/`: Pastas das sprints, contendo `proposal.md`, `design.md`, `tasks.md` e `.openspec.yaml`.

## Protocols
Toda nova feature ou refatoração relevante deve seguir este formato.
